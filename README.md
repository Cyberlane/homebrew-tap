# Cyberlane Homebrew Tap

Homebrew formulae for Cyberlane software.

## Install

```sh
brew install Cyberlane/tap/syncpick
brew install Cyberlane/tap/vlc-media-watcher
```

The `syncpick` formula is updated automatically when a new GitHub release is
published from [Cyberlane/syncpick](https://github.com/Cyberlane/syncpick).

`vlc-media-watcher` can run continuously as a per-user background service:

```sh
brew services start Cyberlane/tap/vlc-media-watcher
```

Setup and privacy details are in the
[vlc-media-watcher documentation](https://github.com/Cyberlane/vlc-media-watcher#readme).
